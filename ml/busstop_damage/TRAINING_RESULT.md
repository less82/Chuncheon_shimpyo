# 정류장 파손 RF-DETR v13 학습 결과

## 결론

- 새 원거리·고각도 버스 충돌 사진 `파손/4830_5592_3830.jpg`에서
  찌그러진 정류장 지붕·프레임만 `other_bus_stop_damage`로 라벨링했다.
- 원거리·회전·원근·조도·흐림·압축·부분 가림 변형 10장을 추가했다.
  기존 기타 시설 증식 2장을 포함하면 이 원본의 학습 레코드는 총 13장이다.
- 최종 모델은 새 사진을 `(버스 정류장 시설) 파손`으로 확정하며, 실제 파손
  구조물만 1개 박스로 반환한다. 신뢰도는 0.2763이다.
- 제공 파손·정상 회귀 26건은 26/26 통과했다.
- 독립 원거리 충돌 원본은 1장뿐이므로 운영 성능을 보증하지 않는다.

## 증식 방식

Albumentations 2.x로 박스 좌표와 함께 다음을 결정론적으로 변환했다.

- 이동·확대/축소·회전·전단·약한 원근
- 밝기·대비·감마·CLAHE
- 가우시안 노이즈·모션 블러·JPEG 압축
- 작은 부분 가림

단순 파일 복사는 증식으로 계산하지 않았다.
동일 명령으로 재생성한 83개 레코드의 박스·증식 시드·이미지 SHA-256도
전부 일치했다.

## 학습 구성

| 항목 | 값 |
|---|---:|
| 모델 | RF-DETR Nano 1.8.3 |
| 초기 체크포인트 | v12 선택 모델 |
| GPU / 해상도 | GTX 1650 Ti 4GB / 384×384 |
| batch / gradient accumulation | 1 / 4 |
| 학습 | 10 epoch |
| 학습률 / encoder 학습률 | `1e-5` / `1e-6` |
| 선택 체크포인트 | 10번째 epoch |

검증 mAP는 최고 0.7143(8~9번째 epoch), 선택한 10번째 epoch는 0.7125다.
8번째 모델보다 10번째 모델이 새 사진의 잘못된 도로 후보와 정상 사진 오탐을
더 잘 억제해 앱 회귀 기준으로 선택했다. 테스트 표시는 0.6876이지만,
검증·테스트 원본의 반복본이 학습에 포함되어 독립 성능으로 해석할 수 없다.
