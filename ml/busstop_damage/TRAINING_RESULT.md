# 정류장 파손 RF-DETR v14 학습 결과

## 결론

- `파손/159339_61595_832.jpg`의 빈 유리 프레임과 바닥 유리 파편을
  `side_glass_damage`로 추가했다.
- 대표 박스는 빈 프레임부터 파편대까지 포함하고, 파편 위치는 별도 보조
  박스로도 기록했다.
- 최종 API는 이 사진을 `(버스 정류장 외벽 유리) 파손` 0.6647로 확정한다.
- 새 사진을 포함한 제공 파손·정상 회귀는 27/27 통과했다.
- 독립 ‘통째로 빠진 유리+파편’ 원본이 1장뿐이므로 운영 성능은 보증하지 않는다.

## 학습 구성

| 항목 | 값 |
|---|---:|
| 모델 | RF-DETR Nano 1.8.3 |
| 초기 체크포인트 | v13 선택 모델 |
| GPU / 해상도 | GTX 1650 Ti 4GB / 384×384 |
| batch / gradient accumulation | 1 / 4 |
| 1차 학습 | 10 epoch, `1e-5` / `1e-6` |
| 박스 보정 | 5 epoch, `5e-6` / `5e-7` |
| 선택 체크포인트 | 보정 5번째 epoch |

표시상 검증 mAP는 1.0000, 테스트 mAP는 0.9252다. 검증·테스트 원본의
반복본이 학습에 포함된 앱 회귀 데이터이므로 독립 성능으로 해석할 수 없다.

대표 파손 영역으로 검출한다.

## 남은 한계

- 빠진 유리·바닥 파편 유형의 독립 원본을 최소 200장 확보해야 한다.
- 작은 파편의 개별 위치가 필요하면 고해상도 세그멘테이션 모델이 필요하다.
- 유형별 독립 검증·테스트를 각각 최소 30장 유지해야 한다.
- 정상 바닥·자갈·빗물·반사 음성 이미지를 최소 300장 확보해야 한다.

현재 모델은 제공 사진 데모와 데이터 파이프라인 검증용이다. 민원 자동 확정이나
보수 의사결정에는 사람이 최종 확인해야 한다.
