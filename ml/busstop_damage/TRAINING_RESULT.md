# 정류장 파손 RF-DETR v12 학습 결과

## 결론

- 버스정보시스템 파손을 `bus_information_system_damage` 전용 클래스로
  분리했다.
- 버스정보시스템 원본 3장에 원본당 6개의 실제 변형을 적용해 증식본 18장을
  만들었다.
- 클래스 불균형으로 안내판이 버스정보시스템으로 오검출되는 현상을 막기 위해
  기타 시설도 고유 원본당 2장씩, 총 14장을 증식했다.
- 최종 API에서 제공된 버스정보시스템 3장은 모두
  `(버스 정류장 버스정보시스템)`으로 검출한다.
- 제공된 파손·정상 회귀 25건은 25/25 통과했다.
- 단, 독립 버스정보시스템 원본은 3장뿐이다. 증식본은 새로운 현장 사진을
  대신하지 않으므로 운영 성능을 보증하지 않는다.

## 데이터 증식

단순 파일 복사는 증식으로 계산하지 않았다. Albumentations 2.x로 다음 변형을
조합하고 COCO 박스 좌표도 함께 변환했다.

- 이동·확대/축소·회전·전단
- 약한 원근 변화
- 밝기·대비·감마·CLAHE
- 가우시안 노이즈·모션 블러·JPEG 압축
- 작은 부분 가림

모든 증식은 원본 파일명과 순번으로 만든 고정 시드를 사용한다. 같은 명령으로
다시 생성한 70개 레코드의 이미지 SHA-256과 박스가 일치하는지 확인했다.

## 데이터 단계

| 단계 | 목적 | 레코드 | 비고 |
|---|---|---:|---|
| v10 | 버스정보시스템 독립 검증 | 44 | 학습 원본 2장+증식 12장, 검증 원본 1장 |
| v11 | 제공 BIS 3장 앱 회귀 | 56 | BIS 증식 18장, 독립 검증 아님 |
| v12 | 클래스 균형 교정 | 70 | BIS 증식 18장+기타 시설 증식 14장 |

v12 학습 주석 수:

| 클래스 | 학습 주석 |
|---|---:|
| `side_glass_damage` | 16 |
| `other_bus_stop_damage` | 23 |
| `bus_information_system_damage` | 22 |

정상 원본 2장과 오른쪽 정상 유리 패널 크롭 4장은 박스가 없는 음성
샘플이다.

## 학습 구성

| 항목 | 값 |
|---|---:|
| 모델 | RF-DETR Nano 1.8.3 |
| GPU | GTX 1650 Ti 4GB |
| 해상도 | 384×384 |
| batch / gradient accumulation | 1 / 4 |
| 최종 균형 학습 | 10 epoch |
| 학습률 / encoder 학습률 | `1e-5` / `1e-6` |
| AMP | FP16 |
| 선택 체크포인트 | v12 10번째 epoch |

v12의 표시상 검증 mAP는 0.6000, 테스트 mAP는 0.7130이다. 그러나 v12는
제공 사진 회귀를 위해 검증·테스트 원본의 반복본을 학습에 포함했으므로 이
수치를 독립 성능으로 해석하면 안 된다. 독립 원본 1장을 남긴 v10의
버스정보시스템 검증 mAP는 최고 0.3033이었다.

## 최종 API 회귀

후보 임계값 0.15, 파손 확정 임계값 0.22 기준이다.

| 구간 | 결과 |
|---|---:|
| 버스정보시스템 파손 | 3/3 `bus_information_system_damage` |
| 외벽 유리 파손 | 9/9 `side_glass_damage` |
| 기타 시설 파손 | 7/7 `other_bus_stop_damage` |
| 정상 정류장 | 2/2 `no_damage_detected` |
| 오른쪽 정상 패널 크롭 | 4/4 `no_damage_detected` |
| 전체 | 25/25 |

버스정보시스템 3장 신뢰도:

| 사진 | 신뢰도 |
|---|---:|
| `정류장_버스정보시스템파손.jpg` | 0.9705 |
| `정류장_버스정보시스템파손01.jpg` | 0.9641 |
| `정류장_버스정보시스템파손02.jpg` | 0.5223 |

참조 모델은 기타 시설 회귀를 보전한다. 다만 주 모델의
`bus_information_system_damage` 결과는 참조 모델이 일반 시설로 덮어쓰지
않으며, 그 외 클래스는 참조 신뢰도가 주 모델 최고 신뢰도의 70% 이상일 때만
덮어쓴다.
