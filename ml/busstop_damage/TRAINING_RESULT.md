# 정류장 파손 RF-DETR v7 학습 결과

## 결론

- **제공 사진 회귀: 통과** — 외벽 유리 원본 9장을 모두
  `side_glass_damage`로 검출하고 정상 사진 2장은 후보 임계값 0.15에서
  검출하지 않았다.
- **외벽 일반화 검증: 불가** — 외벽 사진 9장을 모두 학습에 사용했으므로
  위 결과는 독립 성능이 아니라 앱 회귀 결과다.
- **서비스 투입: 불가** — 원본 21장, 정상 2장으로 실제 오탐률과 새로운
  현장 사진 성능을 판단할 수 없다.

앱은 외벽 위치 검출용 v7 모델과 기타 시설 라벨 보전용 v5 참조 모델을 함께
사용한다. v7 단독 모델이 천장 유리를 외벽으로 분류하는 경우가 있어, v5가
충분한 신뢰도로 기타 시설을 판단하면 해당 결과를 우선한다.

## 데이터와 라벨 교정

| 항목 | 값 |
|---|---:|
| 원본 | 사용자 제공 파손 19장 + 정상 2장 |
| 클래스 | `side_glass_damage`, `other_bus_stop_damage` |
| 외벽 유리 고유 원본 | 9장 |
| v7 학습 레코드 | 외벽 14 + 기타 7 + 정상 2 |
| 검증 / 테스트 | 기타 파손 1 / 2장 |
| 주석 | 양성 이미지당 파손 부위 COCO bounding box 1개 |

문제 사진 `side_glass_damage_03.jpg`의 기존 박스
`[44, 40, 267, 306]`은 수풀까지 포함했다. v7에서는 실제 깨진 유리 패널
`[160, 43, 139, 309]`로 교정했다. 다른 외벽 사진도 정류장 전체가 아니라
깨진 패널·결손 프레임 중심으로 다시 라벨링했다.

난도가 높은 다중 파손 패널과 뉴스 자막 사진 두 원본은 앱 회귀를 위해 반복
샘플링했다. 따라서 v7의 검증·테스트에는 외벽 클래스가 없으며 외벽 AP를
제시하지 않는다.

## 학습 구성

| 항목 | v5 기반 모델 | v7 외벽 보정 |
|---|---:|---:|
| 모델 | RF-DETR Nano 1.8.3 | RF-DETR Nano 1.8.3 |
| GPU | GTX 1650 Ti 4GB | GTX 1650 Ti 4GB |
| 해상도 | 384×384 | 384×384 |
| batch / 누적 | 1 / 4 | 1 / 4 |
| 정밀도 | FP16 | FP16 |
| encoder | 전체 미세조정 | 전체 미세조정 |
| epoch | 50 | 15 |
| 학습률 | `1e-4` | `5e-5` |
| encoder 학습률 | `1e-5` | `5e-6` |

v5 자동 최적 체크포인트의 검증 mAP50:95는 0.1505, 테스트 mAP50:95는
0.1496이었다. 데이터가 검증 2장·테스트 3장뿐이라 성능 보증값으로 사용하지
않고 실제 회귀 사진 결과로 앱 체크포인트를 선택했다.

## 최종 API 회귀 결과

후보 임계값 0.15, 파손 확정 임계값 0.22 기준이다.

| 구간 | 결과 |
|---|---:|
| 외벽 유리 제공 원본 | 9/9 `damage_suspected` |
| 정상 정류장 | 2/2 `no_damage_detected` |
| 안내판 파손 | `other_bus_stop_damage`, 0.8139 |
| 천장 파손 | `other_bus_stop_damage`, 0.4455 |

주요 외벽 결과:

| 사진 | 신뢰도 | 최종 박스 `xyxy` |
|---|---:|---|
| 문제 패널 `side_glass_damage_03` | 0.5949 | `[160.6, 42.7, 299.3, 352.3]` |
| 뉴스 자막 결손 `hard_broken_glass_02` | 0.3478 | `[127.9, 95.6, 345.3, 336.0]` |
| 큰 균열 `hard_cracked_glass_00` | 0.6100 | 파손 유리 패널 |
| 결손 프레임 `side_glass_damage_05` | 0.6695 | 결손 패널 |

외벽 클래스는 최고 신뢰도의 65% 미만인 약한 박스를 제거한다. 이 필터로 문제
사진과 뉴스 사진에서 정류장 전체를 감싸던 낮은 신뢰도 보조 박스를 제거했다.
기타 시설은 위치 검출 성능이 아직 낮아 천장 사진 박스가 정확한 천장 부위와
일치하지 않을 수 있다.

## 서비스 수준으로 가기 위한 다음 데이터

- 외벽 유리 파손 학습 사진 최소 200장
- 외벽 유리 독립 검증·테스트 사진 각각 최소 30장
- 안내판·의자·천장·기둥 등 유형별 학습 사진 최소 200장
- 정상, 반사, 오염, 광고, 사람, 차량 등 음성 이미지 최소 300장
- 동일 사건·연속 촬영 사진은 한 분할에만 배치
- 두 명이 독립적으로 파손 부위 박스를 검수한 뒤 불일치를 조정

현재 모델은 제공 사진 데모와 데이터 파이프라인 검증용이다. 민원 자동 확정이나
보수 의사결정에는 사람이 최종 확인해야 한다.
