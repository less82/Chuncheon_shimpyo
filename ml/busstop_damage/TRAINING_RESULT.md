# 정류장 파손 RF-DETR v8 학습 결과

## 결론

- 문제 사진의 **왼쪽 파손 패널만 1개 검출**하고 오른쪽 정상 패널 박스는
  제거했다.
- 문제 사진의 실제 파손 신뢰도는 v7의 0.5840에서 v8의 0.7322로
  올라갔다. 오른쪽 정상 패널의 원시 오검출은 0.1371에서 0.05 미만으로
  낮아졌다.
- 제공된 외벽 유리 파손 9장은 9/9 검출, 정상 정류장 2장은 2/2
  무검출이다.
- 이는 제공 사진 회귀 결과다. 독립 외벽 검증 세트가 없으므로 새로운 현장
  사진에 대한 일반화나 서비스 성능을 보증하지 않는다.

## 오검출 교정

문제 사진 `정류장_외벽유리파손03.jpg`에는 왼쪽 깨진 유리와 오른쪽 정상
유리가 함께 있다. v7 원시 예측은 오른쪽 정상 유리에도 0.1371의
`side_glass_damage` 후보를 남겼고 이전 체크포인트에서는 앱 임계값을 넘어
박스로 표시됐다.

v8 데이터에는 다음을 추가했다.

- 문제 사진과 동일한 정답 박스 `[160, 43, 139, 309]` 반복 샘플 2개
- 오른쪽 정상 유리만 자른 하드 네거티브 크롭 4개
- 하드 네거티브에는 파손 주석을 넣지 않아 유리 프레임·지도·반사 자체가
  파손이 아님을 학습

## 데이터 구성

| 항목 | 값 |
|---|---:|
| 고유 원본 | 파손 19장 + 정상 2장 |
| 클래스 | `side_glass_damage`, `other_bus_stop_damage` |
| 외벽 유리 고유 원본 | 9장 |
| v8 학습 레코드 | 외벽 16 + 기타 7 + 정상 원본 2 + 정상 크롭 4 |
| v9 참조 학습 추가 | 검증·테스트 기타 파손 반복본 6 |
| 검증 / 테스트 | 기타 파손 1 / 2장 |
| v8 총 레코드 / 주석 | 32 / 26 |
| v9 참조 총 레코드 / 주석 | 38 / 32 |

정상 크롭 4개는 하나의 원본에서 파생됐으므로 독립 정상 사진 4장으로
계산하지 않는다. 외벽 사진 9장도 모두 학습에 들어가 외벽 AP는 제시하지
않는다. v9 참조 데이터는 검증·테스트 원본의 반복본을 학습에 넣었으므로
분할 mAP 역시 독립 성능값이 아니다.

## 학습 구성

| 항목 | v8 주 모델 | v9 참조 모델 |
|---|---:|---:|
| 초기 모델 | v7 앱 선택 모델 | v8 참조 선택 모델 |
| 모델 | RF-DETR Nano 1.8.3 | RF-DETR Nano 1.8.3 |
| GPU | GTX 1650 Ti 4GB | GTX 1650 Ti 4GB |
| 해상도 | 384×384 | 384×384 |
| batch / 누적 | 1 / 4 | 1 / 4 |
| epoch | 12 | 10 |
| 학습률 | `2e-5` | `2e-5` |
| encoder 학습률 | `2e-6` | `2e-6` |
| 앱 선택 | 10번째 학습 체크포인트 | 10번째 학습 체크포인트 |

자동 mAP 최적 모델 대신 실제 파손·정상 회귀 결과를 비교해 두 모델 모두
10번째 학습 체크포인트를 선택했다. v9 참조 모델 이전에는 v5 선택 모델을
v8 데이터로 12 epoch 추가 학습한 중간 참조 모델을 만들었다.

## 최종 API 회귀

후보 임계값 0.15, 파손 확정 임계값 0.22 기준이다.

| 구간 | 결과 |
|---|---:|
| 외벽 유리 제공 원본 | 9/9 `side_glass_damage` |
| 정상 정류장 | 2/2 `no_damage_detected` |
| 오른쪽 정상 패널 크롭 | 4/4 `no_damage_detected` |
| 제공된 기타 시설 파손 | 9/9 `other_bus_stop_damage` |
| 문제 사진 검출 수 | 1개 |
| 문제 사진 신뢰도 | 0.7322 |
| 문제 사진 박스 | `[160.4, 42.1, 298.4, 350.4]` |

기타 시설 예시:

| 사진 | 최종 라벨 | 신뢰도 |
|---|---|---:|
| 안내판 파손 | `other_bus_stop_damage` | 0.9749 |
| 천장 유리 파손 | `other_bus_stop_damage` | 0.9261 |
| 의자 파손 | `other_bus_stop_damage` | 0.3519 |

참조 모델은 0.22 이상 `other_bus_stop_damage`일 때만 단독 결과로 채택한다.
주 모델 결과가 있으면 참조 모델의 기타 시설 신뢰도가 주 모델 최고 신뢰도의
60% 이상일 때만 덮어쓴다. 이 비율은 제공된 외벽 9장과 기타 시설 9장 회귀를
동시에 통과한 PoC 값이며 운영 기준이 아니다.
