# 정류장 파손 RF-DETR 학습 결과

## 결론

- **개념검증(PoC): 통과** — hard-example을 반영한 v2 데이터로 GPU 재학습과 앱 추론까지 재현했다.
- **서비스 투입: 불가** — 정상 정류장 사진이 2장이고 테스트가 2장뿐이라 실제 일반화 성능을 판단할 수 없다.
- 최종 채택 모델은 **RF-DETR Nano v2 전체 encoder 미세조정 모델**이다.

## 데이터

| 항목 | 값 |
|---|---:|
| 원본 | 사용자 제공 파손 사진 17장 + 정상 사진 2장 |
| 클래스 | `bus_stop_damage` 1개 |
| 학습 / 검증 / 테스트 | 15 / 2 / 2장 |
| 학습 구성 | 파손 양성 13장 + 정상 음성 2장 |
| 주석 | 양성 이미지당 파손 부위 COCO bounding box 1개 |

유형별 표본이 1~6장뿐이므로 5개 세부 클래스로 나누지 않았다. 원본 파일은 저장소에 복사하지 않고, 변환 이미지와 COCO JSON은 다운로드 폴더의 산출물에 보관한다.

## 학습 설정

| 항목 | 값 |
|---|---|
| 모델 | RF-DETR Nano 1.8.3 |
| GPU | NVIDIA GeForce GTX 1650 Ti 4GB |
| Python / PyTorch | 3.11.9 / 2.7.1+cu128 |
| 해상도 | 384×384 |
| batch / 누적 | 1 / 4 |
| 정밀도 | FP16 |
| 메모리 절감 | gradient checkpointing, EMA 비활성화 |
| 미세조정 | encoder 포함 30.1M 파라미터 전체 |
| 실행 | 최대 40 epoch, 12회 무개선 시 조기 종료 |
| 실제 종료 | 34 epoch, 최고 체크포인트는 22번째 epoch |

## 결과

| 구간 | mAP50:95 | mAP50 | mAP75 | 정밀도 | 재현율 |
|---|---:|---:|---:|---:|---:|
| 검증 최고 | 0.1909 | 0.8350 | 0.0079 | 0.6667 | 1.0000 |
| 테스트 | 0.1941 | 0.5521 | 0.0776 | 1.0000 | 0.5000 |

hard-example 및 테스트 회귀 검수:

- 학습에 반영한 신규 유리 균열: v1 0.2809 → v2 0.5484
- 정상 사진 1: v1 0.3595 오탐 후보 → v2 0.1110
- 정상 사진 2: v1 0.2468 → v2 후보 없음
- 기존 테스트 천장/안내판 파손: v2 0.3377 / 0.4710으로 `확인 필요`
- IoU 0.5 NMS로 중복 박스를 제거했다.

신규 유리 균열 결과는 학습 반영 여부를 확인한 값이지 독립 성능 평가가 아니다. 위 테스트 수치도 이미지가 2장뿐이므로 성능 보증값이 아니다. 두 장을 모두 검출했다는 사실과 COCO의 재현율 0.5가 다르게 보이는 이유는, COCO 평가는 여러 confidence·IoU 임계값을 종합하기 때문이다.

## 서비스 수준으로 가기 위한 다음 데이터

- 파손 5개 유형별 학습 사진 최소 200장
- 유형별 검증·테스트 사진 각각 최소 30장
- 정상 정류장, 오염, 반사, 광고, 사람, 차량 등 음성 이미지 최소 300장
- 춘천 현장 촬영분을 뉴스 이미지와 분리한 최종 테스트 세트
- 동일 사건·연속 촬영 사진은 한 split에만 배치
- 2인 독립 주석 후 불일치 조정

현재 모델은 데모와 데이터 파이프라인 검증까지만 사용한다. 민원 자동 판정이나 시설 보수 의사결정에 연결하면 안 된다.
