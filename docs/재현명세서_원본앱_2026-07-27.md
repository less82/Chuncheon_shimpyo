## 0. 먼저 읽을 것 — "똑같은 결과물"의 정의와 한계

**바이트 단위로 동일한 산출물은 문서로 보장할 수 없다.** 아래 3가지가 구조적으로 실행마다/환경마다 달라지기 때문이다. 이 문서가 겨냥하는 것은 **"기능 동일 재현"**이고, 아래 항목을 어떻게 고정/대체하는지까지 명시한다.

| 비결정 요소 | 왜 달라지나 | 고정/대체 방법 |
|---|---|---|
| `stops.json`·`routes.json`의 `generatedAt` | `datetime.now(UTC)` 타임스탬프 | 무시(내용 비교 시 이 필드 제외) |
| `tagoNodeId`(현재 1845개) | TAGO 키+네트워크로 빌드 시점 조회 | 커밋된 `stops.json` 그대로 쓰거나, 키 확보 후 재실행 |
| `maeng-coco` 파손검출 모델 | **가중치 2개가 Git 밖**(`~/Downloads/busstop_coco_rfdetr/`) | 원 가중치 파일 확보 필수(§7). 없으면 파손검사 기능만 비활성 |

**재현 성공 판정선(이 문서의 "완료 기준"):**
1. `cd pipeline && python build_stops.py` → `stops.json`(정류장 **1890개**), `routes.json`(노선 **223개**) 생성.

### 3.3 7단계 (입력 → 규칙/반경 → 산출) — `build_stops.py:build()`
Stage 1만 실패 불가, **Stage 2~7은 각각 try/except**(실패해도 앞 단계 보존).

1. **마스터(실패 불가)** — 위치+노선정보. **마스터 키=관리번호(250xxx)**. 노선은 관리번호로 groupby(**이름 조인 금지**). 모든 시설 초기값 `{unknown, none}`.
2. **수요 브리지** — 정류장아이디 직접매칭 0 → **정류장명 정규화(공백 제거)** 매칭. 24시간 승차합 `byHour[24]`+`total`, `aggregatedBidirectional:true`(동명 양방향 합산). 실측 **1667/1890(88.2%)** 매칭. 미매칭은 `demand` 키 없음(=미확인).
3. **의자** — 벤치 좌표 **30m** 이내 → `{yes, bench_registry}`.
4. **조명** — 가로등 좌표 **50m** 이내 → `{yes, light_registry}`.
5. **그늘** — 그늘막 주소(도로명>지번)를 `geocode_cache.json`에서 좌표 조회 → **30m** 이내 → `{yes, shade_registry}`. **캐시에 없으면 skip(네트워크 호출 안 함).**
6. **도착안내기** — 공간매칭 아님. BIT `정류장 번호`(4자리) ↔ 마스터 `stopNo` **정확 일치** → `{yes, sign_registry}`.
7. **로드뷰 오버레이(최우선)** — `roadview_survey_filled.csv` 있을 때만. 관리번호 매칭, `있음→yes / 없음→no / 미확인·빈칸→유지`. **`no`를 만드는 유일한 경로.** `source=roadview`, `capturedAt(YYYY.MM)`.

후처리: `headwayMin` 추정(노선 ≥8→8, ≥4→12, ≥1→15, 없음→20분), `build_routes()`→routes.json, `tago_map`(키 있을 때만 nodeid ≤50m 최근접 → `tagoNodeId`), 엑셀 날짜오염 복원(`"03월 01일"→"3-1"`).

**현재 커밋된 stops.json 분포(참고):** shade yes 4 / seat yes 825 / light yes 808 / **sign 전부 unknown** / no 0 / demand 1667 / tagoNodeId 1845. ⚠️ sign이 전부 unknown인 건 생성 시점 BIT 매칭이 0이었기 때문 — **재실행하면 현재 입력 기준으로 재계산되어 커밋본과 달라질 수 있다.**

## 4. 데이터 계약 (불변) — `app/src/types/stop.ts`

```ts
Facility = "yes" | "no" | "unknown"
Source = "roadview" | "bench_registry" | "shade_registry" | "light_registry" | "sign_registry" | "none"
FacilityInfo { status: Facility; source: Source; capturedAt?: "YYYY.MM" }
Stop {
  id: string          // 관리번호 250xxx (마스터 키)
  stopNo: string      // 물리 표지판 번호
  name, lat, lng
  routes: string[]
  facilities: { shade, seat, light, sign: FacilityInfo }
  demand?: { byHour: number[24]; total; aggregatedBidirectional: true; matchedName }
  headwayMin?: number // 배차 추정(실측 아님, TAGO 폴백 캐시)
  tagoNodeId?: string // TAGO 있을 때만
}
StopsFile { generatedAt; cityCenter:{lat,lng}; stops: Stop[] }
CITY_CENTER = { lat: 37.8813, lng: 127.73 }   // 춘천시청(위치권한 거부 폴백)
```
**절대 규칙(코드 계약):** 기본은 항상 `{unknown, none}`. 파이프라인의 어떤 registry 단계도 `no`를 만들지 않는다 — `no`는 로드뷰 조사에서만. JSON 저장은 `separators=(",",":")` compact, `ensure_ascii=False`. `routes.json`: `RoutesFile{ generatedAt; routes:[{routeId, routeNo, stops:관리번호[] }] }`.

### 5.2 화면 동작 핵심
- **홈(CitizenHome)**: `ImportOnLoad`(대리등록 수신) + 큰 버튼 3개(버스→`/go`, 정류장→`/app/report`, 파손검사→`/maeng-coco`) + 즐겨찾기 상위 2개(`FavoriteStopCard`, 도착정보 표시).
- **상태 알리기(AppReport)**: `locating→find→confirm→issue→done`. geolocation 최근접 3개(`MAX 1500m`), 불편 4종(의자 파손/안내화면 꺼짐/조명 꺼짐/시설물 파손) → `saveReport`(localStorage).
- **QR 키오스크(QrMain)**: home/destination/report. 목적지 음성입력(SpeechRecognition ko-KR)→`findTrips`→노선 후보 최대 3. report는 사진 첨부(1280px 리사이즈 JPEG 0.75).
- **길찾기(TripView `/go`)**: 출발지 `searchPlaces`(Nominatim, 춘천 bbox)+OSM 미리보기, 목적지 stops 매칭 → `planTripToPlace`/`planTrip` → `rankTripArrivals`(**도착시간 우선 정렬**) → 상위 1개 `TripCard`.
- **인쇄(PrintPoster)**: 4시설 3상태 + 정류장 QR(로컬 생성) + 범례 + `로드뷰 조사 YYYY.MM 기준`.
- **파손검사(MaengCoco)**: 사진(≤12MB)→`POST /api/maeng-coco?threshold=0.15`. verdict 3종 표시, 접수 시 `POST /reports`+localStorage. 고지 "시험용 모델, 반드시 사람이 확인".

### 5.3 실시간 도착정보 (`lib/arrivals.ts`) — 정확한 분기
- `VITE_TAGO_KEY` **AND** `stop.tagoNodeId`가 **둘 다** 있어야 실시간 시도. 하나라도 없으면 즉시 폴백.
- TAGO: `apis.data.go.kr/1613000/ArvlInfoInqireService/...cityCode=32010&nodeId=..`, 타임아웃 2500ms. 실패/파싱오류 → 즉시 폴백.
- **폴백 문구(정확)**: `배차간격 약 N분`(N=`headwayMin ?? 15`), `live:false`.
- 실시간 문구: `min<=0 → "곧 도착"`, else `"약 N분 후 도착"`.
- StopCard는 live 아니면 "실시간 도착 정보 없음" 노출.
- 도보(`lib/walking.ts`): OSRM foot(`router.project-osrm.org`, 2500ms) → 실패 시 직선 haversine 폴백, 속도 80m/분.

### 5.4 데이터 로딩 · PWA
- `loadStops`: `/data/stops.json` → 실패 시 `/data/stops.sample.json` 폴백.

### 6.2 대시보드 4탭(`Dashboard.tsx`, 기본 `reports`)
- **reports(시민 제보)**: localStorage `shimpyo:reports` + 5초 폴링 + maeng_coco 원격 병합. 상태 4단계(received→reviewing→task_created→resolved), 모달 검토(필수 체크 2개), 페이지네이션 4.
- **survey(조사 검토, 1단계)** — `surveyPriority.ts`: **demand 있는 정류장만** 랭킹, 없으면 `noDemand` 분리(재정규화 금지). `score = (w.demand·D + w.unknown·UNK [+ w.poi·P]) / Σ활성w`. D=한낮(11~16시) 승차 분위수, UNK=`unknownCount/4`. 프리셋 heat/senior/usage(poi는 senior만). **score는 "지수(보조)" 열에만**, 실측값이 주.
- **install(설치 검토, 2단계)** — `installPriority.ts`: **대상 = `status==="no" && source==="roadview"`만**(yes·unknown 제외). 시설 seat/shade/light(sign 제외). `INSTALL_STATUS_LABEL`("데이터상 설치 검토 후보 · 현장 설치 적합성 미검토").
- **filter(조건 조회, v1)** — `filters.ts`: **합성점수 없음**, AND 조건 + 실측 분위수만. 계절 프리셋 4종.
- **예산 시뮬** `budgetSimulate.ts`: `covered=min(floor(budget/unit), n)`. `dailyBoardings`=covered 중 demand 있는 것만 합, `unmeasuredCount` 별도. 기본 1000만원/80만원.
- **근거 카드** `EvidenceCard`: 미비 내역+근거. **installRow면 "승차 순위" 섹션 숨김**(한 카드 미확인+실측 동시표시 금지). **합성 점수 미표시.**
- **CSV**(`exportCsv.ts`): 전부 UTF8 BOM+CRLF, 승차 헤더에 "양방향 합산" 명시.

## 10. 반드시 지킬 규칙 (정직성 · 표현 금지어)

재구축이 "똑같아야" 하는 가장 중요한 부분은 화면 픽셀이 아니라 **데이터 정직성 계약**이다. 여기가 어긋나면 다른 앱이다.

- 시설은 `yes|no|unknown` 3상태만. **근거 없이 `no` 생성 금지**, 기본 `{unknown, none}`. `no`는 로드뷰 조사에서만.
- **`no`와 `unknown`을 같은 변수·순위 효과로 합치지 않는다.** 미확인→조사 트랙(survey), no→설치 트랙(install).
- 출처 배지: `로드뷰 확인 (촬영 YYYY.MM)` / `○○대장 기준` / `버스정보단말기(BIT) 기준`. **문자열 "현장 확인" 금지**(테스트가 전탭 검사).
- 수요엔 항상 `양방향 합산 기준` + `2025.6 4일 표본` 병기.
- **금지 표현**: "수혜", "일평균", "그늘 4곳뿐", "민감도", 조건 없는 "오프라인 동작". B2C는 **합성 점수 숫자 비표시**.
- 마스터 조인 키 = `id`(관리번호). 이름 조인은 수요 브리지(`matchedName`)만 예외.
- (협업) 사람별 브랜치에서만 작업, `main`/남의 브랜치 직접 push·`--force` 금지, main 병합은 PR로만. TAGO 키는 `app/.env`(gitignore)에만.
